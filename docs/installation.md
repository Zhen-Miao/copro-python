# Installation

## From PyPI

```bash
pip install pycopro
```

## From source

```bash
git clone https://github.com/Zhen-Miao/copro-python.git
cd copro-python
pip install -e .
```

## Requirements

- Python ≥ 3.10
- numpy ≥ 1.24
- scipy ≥ 1.10
- pandas ≥ 2.0
- scikit-learn ≥ 1.3

## Verify installation

```python
import copro as cp
print(cp.__version__)
```
